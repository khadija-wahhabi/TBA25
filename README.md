# TBA25

Auteur

Projet réalisé par Khadija Wahhabi
Dans le cadre du cours Text-Based Adventure (TBA).

Présentation du projet

Ce projet est un jeu d’aventure textuel en Python, réalisé dans le cadre du cours de programmation orientée objet.
Le joueur explore un château, interagit avec des personnages non joueurs (PNJ), collecte des objets et accomplit des quêtes pour gagner la partie.
Le jeu se joue dans le terminal, à l’aide de commandes textuelles.

Fonctionnalités principales

Déplacement du joueur entre différentes pièces
Gestion d’un inventaire avec contrainte de poids
Interaction avec des personnages non joueurs (commande talk)
Déplacement aléatoire des PNJ
Système de quêtes (items, déplacement, interaction)
Système de récompenses
Conditions de victoire et de défaite
Mode DEBUG pour observer le comportement interne du jeu

Commandes disponibles

help : afficher l’aide
go <direction> : se déplacer (N, S, E, O, U, D)
back : revenir à la pièce précédente
look : observer la pièce
take <item> : prendre un objet
drop <item> : déposer un objet
check : afficher l’inventaire
talk <pnj> : parler à un personnage
history : afficher l’historique des pièces visitées
rewards : afficher les récompenses obtenues
quit : quitter le jeu
